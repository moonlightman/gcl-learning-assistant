# 鑫知海学习助手 4.15

适用于 Tampermonkey 的学习辅助脚本，提供目录识别、视频续学、DeepSeek 题目分析及答案填入。答案需自行核对，脚本不会提交试卷。

## 安装与更新

1. 安装 Tampermonkey 后，[点击安装最新版](https://raw.githubusercontent.com/moonlightman/gcl-learning-assistant/main/%E9%91%AB%E7%9F%A5%E6%B5%B7-%E8%87%AA%E5%8A%A8%E7%BB%A7%E7%BB%AD%E5%AD%A6%E4%B9%A0.user.js)。
2. 已安装 4.6 或更早本地版本时，需先安装一次 4.7，才能获得固定更新地址。
3. 后续在油猴管理面板对本脚本选择“检查更新”，或使用油猴定期检查。
4. 更新使用相同脚本名称和 namespace，保留原有本地设置。若浏览器出现重复脚本，请只启用最新版。

更新信息：[learning.meta.js](./learning.meta.js)。完整脚本：[源码](./鑫知海-自动继续学习.user.js)。访问更新需要网络能连接 GitHub Raw。

## 4.15 亮色极简浮窗与考试名称

- 浅灰白磨砂底、白色分组卡片、系统蓝主操作；标题和页脚固定，中间内容滚动，保留最小化、拖动及原有功能。
- 不透明度现在调整背景，文字及控件保持清晰。无需重置旧设置。
- 考试名称放在题目助手顶部，自动读取考试区域的标题；没有明确标题时尝试页面标题。支持页面异步加载，并在读取题目/导出前同步。
- 可以手动修改名称，同一课程不会覆盖手改值；清空后恢复自动读取。课程切换会清除原课程的手改状态；名称不明时保留空白并提示填写。
- 分析期间名称变化仍会阻止填入旧结果；保留原有确认及不自动提交试卷规则。
- 「自动开始学习」按钮简化为「开始学习」；题目操作简化为「读取题目」「逐题分析」。
- 验证：已检查标准宽度、260px 紧凑布局和最小化的本地浏览器预览；现有回归及新增考试名/导出/手改/异步加载/切换/透明度测试通过。尚未在真实油猴考试页面验证新版名称识别或学分入账。

## 4.13 独立单视频

- 新增 `#/video/play?kngId=…` 页面，浮窗显示「单视频」及平台进度。无需培训大纲；暂离和多端提示共用原有检测规则。
- 点击「自动开始学习」后，识别唯一的「开始学习／继续学习」入口并等待播放器；已有播放器时尝试播放一次。浏览器阻止播放或加载超时时提示手动处理，不重复点击。
- 播放途中手动暂停后需手动恢复；「停止续学」停止自动控制，当前视频仍可播放。
- 播放结束后等待平台完成标记。支持进度条 100% 及平台替换显示的「已完成学习」，连续三次检测后提示完成；同一完成标记兼容文档页。
- 验证：真实单视频页面已核对学习入口按钮与进度条，未点击入口或安装新版完整运行。模拟覆盖入口、播放拒绝、超时、多播放器、暂停/停止、暂离、多端冲突、结束等待、完成标记及切换课程；未验证真实播放和学分入账。

## 4.12 文档暂离与多端提示

- 文档与视频共用已有弹窗识别：检测到「已触发防挂机验证」时点击一次「继续学习」，弹窗消失后再计数；停留期间不连点、不翻页。
- 检测到「您已经打开过该课程」并询问「确认是否仍在此页面学习」时确认一次。两分钟内再次冲突会停止自动续学，请关闭其他课程页后手动确认并重新开始。
- 弹窗期间重置翻页等待，保留平台学习时长及完成标记判断；不处理其他未知登录提示。
- 验证：模拟文档页覆盖暂离、重复检测、消失后计数、多端冲突及再次冲突停止；全套回归通过。尚未在真实文档弹窗上运行新版或验证学分入账。

## 4.11 文档阅读

- 打开鑫知海文档课程（`#/doc/play?kngId=…`），点击浮窗「开始学习」。
- 设置页可修改文档翻页间隔，默认 90 秒，范围 10～600 秒，自动保存。保持阅读页可见；隐藏页面或有弹窗时暂停翻页。
- 从当前页开始逐页翻阅；到末页后等待平台计时。仅当平台进度连续三次显示 100% 才提示完成，不缩短平台要求的学习时长。
- 「暂停」暂停检测与翻页，「停止续学」关闭自动翻页。翻页失败或页码不明时停止并提示；切换课程后需重新开始。
- 验证：已在真实登录文档页核对页码、工具栏及进度控件；模拟测试覆盖间隔、暂停恢复、停止、翻页失败、末页等待及完成标记。尚未将新版安装到真实页面进行完整运行或验证平台学分入账。

## 4.10 使用说明

- 更新后刷新课程页面，只保留一个课程播放页。识别“您已经打开过该课程”且询问是否仍在此页面学习的弹窗，确认一次；两分钟内再次冲突则停止自动续学并提示关闭其他播放页。
- 搜题面板 → **读取题目并下载 Excel**：下载真实 `.xlsx`，包含题目选项、页面已选答案、本次分析答案及说明和来源。先分析再下载可保存分析答案；未分析也能导出题目和已选答案。
- 只读取当前已加载的题目；页面标注题数不符时阻止导出。图片只标记，需人工核对；分析答案不表示官方正确答案。
- 移除历史题库保存、复用与成绩归档；旧油猴题库不读取、不覆盖，不会上传仓库。本次分析结果仅存在页面内存，刷新前请下载。
- 验证范围：模拟页面与导出文件结构验证；未在真实登录课程、真实播放冲突或真实 DeepSeek 接口进行验证。

## 当前功能

- 优先按“培训大纲”下的“视频｜标题”控件识别章节，排除考试；旧选择器保留为兼容备用。
- 检测平台完成标记后接续视频。状态无法确认、章节重名或切换失败时停止并提示。
- 可拖动、最小化和调整透明度的浮窗。
- 填答间隔可调 0.5～50 秒，默认 4 秒，自动保存。
- 可选 DeepSeek 官方 Search 检索，每题先搜索再分析，显示实际来源链接；关闭时只使用模型知识。
- 读取单选、多选、判断题；逐题请求、有界重试、停止和同题单接续。
- 填入前匹配题干和选项，跳过不确定答案及图片题，不自动提交。
