# 鑫知海学习助手 4.7

适用于 Tampermonkey 的学习辅助脚本，提供目录识别、视频续学、DeepSeek 题目分析及答案填入。答案需自行核对，脚本不会提交试卷。

## 安装与更新

1. 安装 Tampermonkey 后，[点击安装最新版](https://raw.githubusercontent.com/moonlightman/gcl-learning-assistant/main/%E9%91%AB%E7%9F%A5%E6%B5%B7-%E8%87%AA%E5%8A%A8%E7%BB%A7%E7%BB%AD%E5%AD%A6%E4%B9%A0.user.js)。
2. 已安装 4.6 或更早本地版本时，需先安装一次 4.7，才能获得固定更新地址。
3. 后续在油猴管理面板对本脚本选择“检查更新”，或使用油猴定期检查。
4. 更新使用相同脚本名称和 namespace，保留原有本地设置。若浏览器出现重复脚本，请只启用最新版。

更新信息：[learning.meta.js](./learning.meta.js)。完整脚本：[源码](./鑫知海-自动继续学习.user.js)。访问更新需要网络能连接 GitHub Raw。

## 当前功能

- 优先按“培训大纲”下的“视频｜标题”控件识别章节，排除考试；旧选择器保留为兼容备用。
- 检测平台完成标记后接续视频。状态无法确认、章节重名或切换失败时停止并提示。
- 可拖动、最小化和调整透明度的浮窗。
- 填答间隔可调 0.5～50 秒，默认 4 秒，自动保存。
- 可选 DeepSeek 官方 Search 检索，每题先搜索再分析，显示实际来源链接；关闭时只使用模型知识。
- 读取单选、多选、判断题；逐题请求、有界重试、停止和同题单接续。
- 填入前匹配题干和选项，跳过不确定答案及图片题，不自动提交。

## 接口与本地存储

在设置页填写 API Key、接口地址和模型。密钥保存于油猴私有存储，仓库不包含密钥。开启联网时搜索和模型分别调用，可能分别产生费用；检索权限及价格以服务商为准。代理接口的密钥未必可用于官方搜索。

## 历史版本

4.0～4.7 的原始脚本保存在 [versions](./versions/)，并有对应 Git 标签。历史版本为实际保存文件，不补造缺失版本；后续修改同时记录提交、版本文件和更新说明。

详见 [CHANGELOG.md](./CHANGELOG.md)。下载旧版用于回退时，请留意新版自动更新地址可能再次提示升级。

## 验证范围

4.6 的目录识别已在实际课程页面验证读到 3 节视频并排除考试；完整自动连续播放尚未验证。联网检索通过模拟测试，尚未使用用户密钥进行真实调用。4.7 仅增加更新信息及版本号，不改变上述业务逻辑。

网站可能调整控件或完成图标；分页、虚拟列表和未展开目录可能无法完整读取。内部制度知识库尚未实现。
